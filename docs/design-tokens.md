# 小窝 · Design Tokens 说明书（宪法 v2.0）

> 所有页面只允许引用 `css/tokens.css` 里的变量，禁止私写数值。
> 要改样式 → 改 tokens → 全站生效。组件文件里出现裸数值，视为 bug。

v2.0 变更：强调色改为干玫瑰系（取自用户参考图板 2）、新增**磨砂玻璃**材质层、
**蕾丝/意象装饰套件**、**夜幕模式**（第十章）。

---

## 一、颜色角色

### 1. 背景层级（最多三层）

| 角色 | 变量 | 白昼 | 夜幕 | 用途 |
|---|---|---|---|---|
| 页面底 | `--paper` | `#F5F4F1` | `#131313` | 机身内底色 |
| 卡片 | `--card` | `#FFFFFF` | 半透明 | 实体卡面 |
| 机身外 | `--stage` | `#EBE9E3` | `#0B0B0C` | 桌面端手机后的桌面 |

### 2. 文字三级

| 级别 | 变量 | 白昼 | 夜幕 | 用途 |
|---|---|---|---|---|
| 主文字 | `--ink` | `#26221E` | `#EEE6E7` | 标题、正文 |
| 次要 | `--ink2` | `#4A443D` | `#CFC6C9` | 辅助说明 |
| 弱化 | `--sub` | `#9B948A` | `#8E8589` | 注释、占位符、图标 |

### 3. 线条与轨道

| 角色 | 变量 | 用途 |
|---|---|---|
| 细线 | `--line` | 卡片描边、分割线 |
| 弱线 | `--line2` | 虚线框、添加按钮 |
| 轨道 | `--fill` | 进度条 / 圆环底色 |

### 4. 强调色（干玫瑰 · 全站唯一，占比 ≤ 5%）

| 档位 | 变量 | 白昼 | 夜幕 | 用途 |
|---|---|---|---|---|
| 正常 | `--accent` | `#9E6A71` | `#C08F99` | 点缀：today、进度、选中 |
| 深档 | `--accent-deep` | `#7E5259` | `#D8B4BB` | 渐变卡上的文字 |
| 浅档 | `--accent-soft` | `#F0E2E3` | 半透明 | 按下底色 |

**规则：强调色只给"当前最重要的那一个元素"。** 一页里同时抢戏的元素不超过一个。

### 5. 重点卡渐变

`--cream1 / --cream2 / --cream3`：白昼为雾粉渐变（`#F9F0EF → #F0DCDA → #E5CFCB`），
夜幕为深玫瑰烟渐变（`#2A2226 → #1E191D → #171316`）。

## 二、间距（8 的倍数体系）

| 变量 | 数值 | 用途 |
|---|---|---|
| `--sp-page` | 24px | 页面左右边距 |
| `--sp-sec` | 22px | 板块间距（必须 > 卡片间距） |
| `--sp-card` | 12px | 卡片间距 |
| `--sp-in` | 18px | 卡片内边距 |
| `--sp-dock` | 16px | dock / 特殊卡片的边距 |

> 口诀：**同级一档，上级永远比下级松。**

## 四、字体

### 字重（只留三档）
`400` 正文 / `500` 强调数字、标签 / `600` 标题

### 字号阶梯（只增不减，勿造新档）

| 变量 | 数值 | 用途 |
|---|---|---|
| `--fs-kick` | 9.5px | 英文小标签（WEATHER / QUOTA），字距 .26em |
| `--fs-note` | 11px | 注释、辅助信息 |
| `--fs-body` | 13px | 正文基准 |
| `--fs-body-lg` | 15px | 日记等强调正文 |
| `--fs-h2` | 24px | 页标题 |
| `--fs-hero` | 32px | 首页大标题 |

### 行高
- 正文 `--lh-text` = 1.75
- 标题 `--lh-title` = 1.35

### 字体族
- `--sans`：系统无印，负责一切 UI 文字
- `--serif`：Noto Serif SC，负责中文标题、日记正文
- `--disp`：Cormorant Garamond，负责大数字、日期、kicker

### 数字
大数字必须 `font-variant-numeric: tabular-nums`，防跳动。

## 六、组件状态清单

每个组件写样式时必须覆盖：

- **卡片**：默认（磨砂玻璃，见第七章）
- **按钮**：默认 / 按下（`:active` 缩放或变深）
- **输入框**：默认（无底、下划线透明）/ 聚焦（下划线强调色）
- **空状态**：虚线框 + 一句话引导 + 本页意象（见第九章）
- **删除操作**：弱化灰 ×，按下变强调色

## 七、材质：磨砂玻璃

| 变量 | 白昼 | 说明 |
|---|---|---|
| `--glass-bg` | `rgba(255,255,255,.62)` | 玻璃底 |
| `--glass-line` | `rgba(38,34,30,.07)` | 玻璃描边 |
| `--glass-blur` | `18px` | 模糊半径 |

用法：`background + backdrop-filter:blur + 1px 描边` 三件套。
机身底色铺**梦核氛围光**（`base.css` 的 `.phone::before`，雾蓝/雾粉/薄荷三团柔光），
玻璃卡浮在上面才有东西可糊。夜幕下氛围光自动转暗。

---

## 八、装饰：蕾丝套件

**蕾丝 = 线稿卷草纹，不是织物照片。** 全套 SVG 在 `index.html` 顶部的 sprite 里，
`<use href="#orn-xxx">` 引用：

| id | 名称 | 状态 |
|---|---|---|
| `orn-corner` | 蕾丝角花 | ✅ 已用（纪念日卡、日记卡） |
| `orn-bow` | 蝴蝶结 | 储备 |
| `orn-vine` | 藤蔓分隔线 | 储备 |

**硬规则：**
1. **一页最多一处蕾丝**（角花或边框，二选一）。
2. 线宽 1.3px，颜色用 `--accent-deep` 或 `--sub`，透明度 ≤ .45。
3. 蕾丝是"信纸角"，不是"桌布"——宁可没有，不可铺满。

## 九、意象：受控意象库

梦核元素入册管理，`<use href="#orn-xxx">` 引用：

| id | 意象 | 分配 |
|---|---|---|
| `orn-spark` | 星 | 首页（TOGETHER、hero） |
| `orn-butterfly` | 蝴蝶 | 相册（空状态） |
| `orn-moon` | 月 | 日记（输入框脚、空状态） |
| `orn-bow` | 蝴蝶结 | 储备（≤2 个/页） |

**硬规则：每页只选一个主意象，同页可重复出现，不跨页混用。**
新意象先画进 sprite，再到本章登记，最后才能在页面用。

## 十、夜幕模式

`document.documentElement.dataset.theme = 'night' | 'day'`，CSS 变量整体切换，
过渡 0.5s。三档：**自动**（19:00–06:00 落夜）/ **白昼** / **夜幕**，
在「更多 → 外观」切换，存 `xw-theme`。

夜幕设计要点（取自参考图板 3、5）：
- 底色 `#131313` 墨黑，文字瓷白 `#EEE6E7`
- 强调色升为 `#C08F99`，带微光
- today 圆点、额度环加**发光**（`box-shadow` / `drop-shadow`）
- 氛围光转深蓝玫瑰，像月亮照进来

## 文件分层

```
css/tokens.css   宪法（只有变量，含夜幕覆盖块）
css/base.css     骨架 + 机身氛围光 + 装饰套件默认样式
css/home.css     首页（意象：星）
css/pages.css    子页（意象：蝴蝶 / 月）
css/dock.css     底部导航

js/store.js      命名空间 + 本地存储 + 工具
js/widgets.js    首页小组件 + applyTheme
js/pages.js      子页逻辑
js/main.js       启动入口

index.html       入口 + 意象 sprite + 防闪烁主题脚本
docs/design-tokens.md  本说明书
```

引用顺序固定：**tokens → base → home → pages → dock**；脚本 **store → widgets → pages → main**。
